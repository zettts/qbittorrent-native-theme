# qBittorrent macOS Light v7

Target: qBittorrent 5.2.3 on macOS, Light mode.

Changes from v6:
- Replaces all Preferences sidebar icons with a consistent monochrome macOS-style set.
- Behavior: sliders
- Downloads: download arrow
- Connection: network nodes
- Speed: speedometer
- BitTorrent: globe/network
- Search: magnifying glass
- RSS: RSS waves
- WebUI: browser/window
- Advanced: compact settings gear
- Includes qBittorrent fallback icon aliases so the set remains consistent.
- Keeps the compact 40px toolbar, 24px toolbar icons, #FCFCFC background, and v6 spacer-removal rules.

Install the .qbtheme in qBittorrent Preferences -> Behavior -> Interface -> Use custom UI Theme, then restart qBittorrent.
